# Development Stages

## Stage 1: Project Setup

Create the repository foundation, documentation, environment templates, and project structure.

## Stage 2: Backend API

Scaffold the backend service and establish the initial API architecture.

## Stage 3: Frontend Foundation

Scaffold the frontend application and establish the main product layout.

## Stage 4: Image Upload System

Add road image upload, validation, preview, and storage workflows.

## Stage 5: AI Detection Engine

Integrate the AI model pipeline for pothole and crack detection.

## Stage 6: Detection Results

Display AI detection outputs, confidence scores, severity estimates, and review states.

## Stage 7: Database Architecture

Design and implement the database schema for users, images, detections, reports, and cases.

## Stage 8: Damage Registry

Create a searchable registry of detected road defects and inspection records.

## Stage 9: Interactive GIS Map

Add map-based visualisation for defects, locations, severity, and inspection coverage.

## Stage 10: Automated Reporting

Generate council-ready reports from detections, cases, maps, and analytics.

## Stage 11: Case Management

Track damage cases from detection through triage, assignment, repair, and closure.

## Stage 12: Analytics Dashboard

Provide operational analytics for severity trends, location clusters, repair status, and reporting.

## Stage 13: Enterprise UI/UX

Polish the product interface so it feels professional, reliable, and suitable for civic infrastructure teams.

## Stage 14: Security & Deployment

Add production-grade security, environment management, hosting, and deployment workflows.

## Stage 15: Portfolio & Presentation

Prepare the final project presentation, demo flow, case study, and portfolio-ready materials.
